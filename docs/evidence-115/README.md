# #115 结语不压红巨星：真实空闲时长复核证据

真实空闲时长（`lib/viewerControl` 默认值：30s resume / 3s ramp / 60s epilogue / 8s lead，全程不使用 `?idle-*` 压缩参数）下，结语落定后结语文字包围盒（`epilogue-text` 的 DOM 盒，含内边距）与红巨星屏幕投影（`data-mira-a-screen` 探针圆心 + `screenDiscRadiusPercent` 半径，`PHYSICS.MIRA_A.radius × 1.4`，与顶栏/终幕标题的 字不压星 证明同一标准）的实测间距。日期固定 `?epoch=2026-09-12`，`?quality=low`（软件渲染）。

## 复核结论

- 桌面 1440×900（zh）：不相撞，横向间距约 +20px——原来的 `CAMERA.CLOSING` 取景在该语言下勉强成立。
- 桌面 1440×900（en）：**相撞，重叠 -14px**。复审截图的怀疑在真实时长下成立（但成因不同：压缩复审看到的是镜头未飞完时的擦边，真实时长是 共同前行 抵达后英文行更宽的包围盒压上 ×1.4 圆盘）。
- 390×844 竖屏（zh/en）：不相撞，纵向间距 +121px / +104px，竖屏取景无需调整。

## 取景调整

`CAMERA.CLOSING.lookAt` x：`-8 → -9.5`（`src/constants/animation.ts`，仅横屏；竖屏 `PORTRAIT_CAMERA.CLOSING` 不变）。look-at 向左加深，双星整体向右移约 2.9% 屏宽（约 42px）。相机位置与 fov 不动。
