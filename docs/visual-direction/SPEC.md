### Wayfinder C：穿行体积

桌面是主要观看场景。尾巴不再只是双星背后的远景，而要进入观看者所在的前景：近处薄雾越过画面边缘，中景保留可读的流向，远处收束到双星。移动端保留完整关系和 reduced-motion，但不为追求最低性能削弱桌面层数。

目标质感参考：[去塑料感目标样张](wayfinder/no-plastic-target-v1.png)。它定义体积、明暗和材质气质，不作为整张背景图直接贴入场景。

密度素材中的闭合涡旋不代表星体、轨道或叙事节点。禁止多层同相叠加形成浅色高亮圈；各层应错开比例与相位，最亮部分沿尾巴方向延伸。白矮星附近只保留柔软、断续的吸积弧，不呈现完整硬圆环。

## 体验与技术边界

1. 双星近看有体积与表面活动，两颗星之间有细腻物质流，小星的吸积光流柔软，不呈现硬质土星环。
2. 相伴运动缓慢且有回应。真实时间可调节底层亮度，但不要求视觉运动遵守真实轨道速度。
3. 镜头拉远，光河逐层展开；前中后景产生视差。回访仍应便捷，延续既有直达/重播能力。
4. 图像提供局部密度、纹理与薄雾；R3F/Three.js 负责空间、遮挡、运动、镜头和交互。整张概念图不作为可交互主场景。
5. 移动端重新安排纵向或斜向构图，不能仅裁切桌面宽画面。保留 reduced-motion、现有语言和信息卡能力。
6. 沿用已安装技术栈；先以少量曲面和单张密度素材证明效果，再决定是否需要更多贴图。不增加模式面板、滑杆或新的渲染依赖。

## 材质实验

入口：`/experiments/river-study.html`，运行现有 `npm run dev` 即可访问。它不在生产首页入口中；素材在 experiments 内，不进入 Vite 的 public 静态复制路径。

- 单张 AI 灰度气流素材映射到 5 层弯曲网格，以亮度控制透明度，shader 着色并做微小 UV 扰动。
- 两颗程序化球体用于测试遮挡和比例；不代表最终星体美术。
- 允许有限角度拖动与缩放，产生真实几何视差；不是完整体积模拟。
- 柔边遮罩消除黑底卡片；不使用循环 UV 平移，避免非平铺素材接缝。
- 当前禁用自主动画的 reduced-motion 下，仍允许主动拖动。

已验证：Chromium 桌面与 390×844 页面载入；纹理就绪；无捕获到的 JS/console error；拖动改变画面；不操作时材质变化；手机无横向溢出。查看 [桌面](evidence/desktop.png)、[拖动后](evidence/dragged.png)、[竖屏](evidence/mobile.png)。

视觉检查：当前光河边缘未见矩形黑底，层次随视角变化；竖屏经修正后双星与主要光河均入画。当前偏暗、星体简陋，尚未达到目标样张。极端自由视角的薄片感、真实手机帧率/发热、长时间运行和最终触控手感尚未验证。若正式场景需要不受限全角度探索，必须在接入前处理薄片暴露，不可偷偷缩减现有交互能力。

## 正式验收

- 默认远景同时表达两颗星的关系和光河尺度；近景保留可辨星体细节。
- 选定视角下无矩形边缘、明显重复层、硬切接缝、穿帮遮挡或大片过曝。
- 拖动与拉远能看到前后景差异；不是完整图片整体平移。
- 桌面、390px 竖屏、减少动态效果分别验收；同一相机与时刻保留 before/after。
- 在选定真实手机记录设备、浏览器、质量档及帧率；目标交互中持续达到约 30 fps，失败则减少层数/分辨率。模拟器不作为真机结论。
- 用户确认美术接近梦幻色彩与震撼纵深后，才算视觉完成；构建或 E2E 通过不替代视觉验收。
