# 从"给妻子的礼物"重新定位为"每日回访的活的星空"

项目文档长期存在定位漂移：`PROJECT_MIRA.md` 写"浪漫礼物兼作品集"，`gan-harness/product-direction.md` 写"伪装成科学可视化的情书，personal first"，两者驱动的形态互相矛盾，是历次"怎么改都不满意"的根因。2026-09-12 拍板：主要观看者是项目主人本人，产品是反复把玩的沉浸式体验；耐看机制以真实时间绑定为主（Mira 约 332 天变星周期 + 双星轨道位置随真实时钟变化），内容发现为点缀。浪漫文案保留，但"礼物/情书"不再是产品定位。

- 作品集定位：再次被否——product-direction.md 04-27 已明确拒绝。
- 纯氛围动态壁纸：被否——不变化的东西撑不起回访。
