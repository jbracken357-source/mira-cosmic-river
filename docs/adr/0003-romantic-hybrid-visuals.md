# 以相伴的浪漫为核心，采用局部生成素材与实时 3D

2026-09-12 观看者确认，2026-09-13 落地记录。

观看者明确希望表达自己与妻子永远相伴的关系，认同“彼此牵引、共同前行”，运动中保留追随的感觉。要求美、浪漫、震撼，允许牺牲天文严谨性，不希望观看流程增加大量说明。

决策：采用已选梦幻版的蓝紫/珍珠金与柔软气流，结合震撼版的尺度和纵深。AI 生成局部密度素材，实时 3D 负责星体、光流、空间关系和镜头。完整概念图是美术参考，不是主场景背景。可见轨道是慢速艺术表达；真实时钟仍影响亮度，但不承诺精确观测位置。

此决策补充 ADR-0001：每日回访、直达和可重播保留；旧定位中对“礼物/情书”的否决不能被解释为禁止浪漫关系成为视觉核心。沉浸画面优先，科学资料退到主动打开的信息卡与开发文档。

结果：两张本地 WebP 密度素材、分层曲面光河、球面纹理与程序化回退；吸积盘降低过曝、物质流保持连接；取消常驻轨道示意线，公转放慢；横屏展示远景，竖屏斜向布局。参见 docs/visual-direction/INTEGRATION.md 的范围与验证记录。
