# 06：主动开启并可靠恢复的环境音

状态：已发布为 GitHub issue #22（ready-for-agent）；有阻塞边时不可提前领取。

## Parent

#18（总 Spec）。

## What to build

交付默认静音、无歌词旁白、覆盖完整开场与自由观看的环境音，克制地随空间距离变化；偏好和实际播放状态分开。

## Acceptance criteria

- [ ] 主动开启才播放，记住偏好；浏览器拒绝或音源失败有真实反馈和重试入口，视觉不中断。
- [ ] 重播及连续切换不会叠加音轨或泄漏资源；明确关闭者不会自行恢复。
- [ ] 后台淡出/暂停，恢复前台不补播积压声音且尊重播放许可。
- [ ] 素材/合成来源和使用权可追溯，无未经同意的新付费依赖。
- [ ] 桌面与手机能力路径、键盘/名称、静音/失败/恢复的行为测试齐全；提供观看者试听材料与记录方式，声音美术认可在 12 收口，不在本票关闭。

## Blocked by

None (can start immediately).
