# 01：光河在主视角形成可信体积

状态：已发布为 GitHub issue #19（ready-for-agent）；有阻塞边时不可提前领取。

## Parent

#18（总 Spec）。

## What to build

在现有实时场景中校准颜色输出、密度与受光，形成近景柔雾、中景主体、远处双星的连续光河。以相同日期/镜头/相位与当前基线比较，先证明低成本路径；新素材或局部体积实验仅在现有路径不足时使用。

## Acceptance criteria

- [ ] 默认与至少三个旋转视角具有真实视差，无矩形边缘、重复亮圈或明显接缝；自由探索不受新限制。
- [ ] 亮部有细节、暗部有结构，光河方向清楚，不靠全局 bloom 或单纯加粒子数取得效果。
- [ ] 桌面与竖屏/减少动态效果路径可展示；贴图失败有确实可见的程序化回退。
- [ ] 记录素材来源、使用权和用途，资源可释放；提供相同基线的前后对照供观看者确认。
- [ ] 交付可复现的截图基线方法：固定日期、随机种子、相机与动画相位，冻结星空闪烁（可从 experiments/ 现有 capture 脚本起步），前后对照用同一方法取得。
- [ ] 工程 build/lint 与相关回归通过；这是可运行的视觉切片，不交付孤立素材文件。
