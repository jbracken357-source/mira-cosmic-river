## What to build

统一自主运镜、主动探索、读卡、保存、完整开场、结语、暂停与后台的控制权；交付暂停和回到主视角的轻量入口。

## Acceptance criteria

- [ ] 最后一次有意输入30秒后以约3秒渐进恢复自动运镜，60秒后允许结语；不瞬间跳回镜头。
- [ ] 两个阈值共用最后有意输入起点，自动运镜不重置时钟；暂停覆盖镜头/轨道/装饰，回前台不解除暂停，手动恢复重新计时且不绕过减少动态效果。
- [ ] 读卡、保存、手动暂停、后台及减少动态效果抑制闲置接管；结束后重新计时。
- [ ] 第一次拖动/滚轮/触摸/按键立即打断运镜和结语，不等待轮询。
- [ ] 主视角恢复、完整开场重播和减少动态效果的优先级明确，不被另一个镜头写入覆盖。
- [ ] 以真实页面操作验证阈值、重复开关和打断；必要纯规则测试覆盖状态优先级。
