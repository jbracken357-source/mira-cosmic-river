# 02：双星与来流形成统一质感

状态：已发布为 GitHub issue #25（ready-for-agent）；有阻塞边时不可提前领取。

## Parent

#18（总 Spec）。

## What to build

在新的光河背景中统一巨星、白矮星、吸积弧与来流。相伴运动中保持可读的双星关系和连续连接。

## Acceptance criteria

- [ ] 近景和远景均能辨别双星，核心无大片死白，巨星避免满表面同强度高频纹理。
- [ ] 吸积流为柔软断续弧，来流与热斑随两星运动保持连接，无明显硬质完整圆环。
- [ ] 时间绑定、信息卡、自由旋转和减少动态效果不回归。
- [ ] 同日期/相位的桌面近远景、旋转及竖屏对照和行为回归齐全。
