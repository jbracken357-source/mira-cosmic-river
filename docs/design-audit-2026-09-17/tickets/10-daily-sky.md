# 10：不同日期的天空变化保持统一且耐看

状态：已发布为 GitHub issue #27（ready-for-agent）；有阻塞边时不可提前领取。

## Parent

#18（总 Spec）。

## What to build

在已有真实时间绑定上，将局部色温、亮度和微妙密度变化协调起来，让不同日期可感知而不破坏最终美术。

## Acceptance criteria

- [ ] 单一确定性时间来源驱动变化；相同日期/相位可复现，不新增实时观测承诺。
- [ ] 选取代表日期对照，变化细腻且不会让尾巴消失、星体过曝或两星难以辨认。
- [ ] 暂停/后台后更新到当前时间但不补播积压动作，导出使用按下时的同一状态。
- [ ] 现有相位信息、里程碑、语言和直达/重播行为不回归；纯时钟与页面回归通过。
