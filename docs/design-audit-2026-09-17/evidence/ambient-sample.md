# 环境音试听材料（#22）

`ambient-sample.wav` — 15 秒、44.1 kHz、16-bit 单声道，2026-09-17 生成。

## 生成与记录方式

```
node experiments/render-ambient-sample.mjs
```

脚本通过 vite dev server 在 OfflineAudioContext 里加载应用同一份合成模块
（`src/lib/ambientGraph.ts`），离线渲染 15 秒后在本仓库编码为 WAV；试听材料
不会与线上实现漂移。

## 来源声明

声音为**原创程序化合成**（AI 辅助编写的 WebAudio 振荡器、程序化生成噪声与
LFO），不含任何音频文件或第三方素材；无旋律、无节拍、无旁白、无歌词。可自由
使用与再生成。详见 `docs/visual-direction/ASSETS.md`。

## 声音设计

- 噪声床：程序化滤波的循环噪声 → 低通（随观看距离 380–760 Hz 微调）→ 慢速 LFO 起伏
- 低频长音：54 Hz 与 54.27 Hz 双正弦微失谐（约 4 秒一次的缓慢拍频，非节拍）
- 高频空气感：162.5 Hz 极轻正弦，慢速起伏
- 主增益基准 0.16，渐强渐弱 0.8 s；距离只作克制的明暗/轻重变化
