# #129 光河改版：前后对比证据

每张图左边是改动前（master `d73250f`），右边是改动后（`da2fad0`）。`nights-max-min.jpg` 例外：两边都是改动后，左边是亮度极大，右边是亮度极小。

## 截图条件

- 本机 headless Chromium，dpr 1，画质固定为 high。
- 对比组用 `experiments/baseline-harness.mjs` 的 `captureViews` 拍摄：`?capture=1` 冻结时间与镜头，纪元 `2026-09-12T00:00:00Z`。桌面 1440×900，竖屏 390×844。
- `live-companion-before-after.jpg` 不冻结时间，是页面打开约 25 秒时的画面（`?quality=high`，直达）。截图时刻不同，伴星位置会略有差别。
- `nights-max-min.jpg` 的纪元分别是 `2026-04-10T12:00:00Z`（亮度极大）和 `2026-11-28T12:00:00Z`（亮度极小）。

## 测量

数字由同一脚本计算：整帧平均亮度（Rec.709 加权，0–255），以及亮度高于 128 的像素占比。参考样张 `docs/visual-direction/wayfinder/no-plastic-target-v1.png` 的这两个数是 37.4 和 7.47%。

| 画面 | 平均亮度 前 → 后 | 高于中灰 前 → 后 |
| --- | --- | --- |
| 默认视角 | 7.68 → 14.78 | 0.14% → 0.87% |
| 实时（伴星） | 7.78 → 15.30 | 0.15% → 1.07% |
| 近景 | 20.95 → 38.87 | 0.45% → 3.39% |
| 侧视 az90 | 8.96 → 9.25 | 0.37% → 2.01% |
| 竖屏 | 8.27 → 11.98 | 0.20% → 1.11% |

亮度极大与极小两晚（默认视角）：改动前 8.73 / 7.35，改动后 17.18 / 13.70；改动后高于中灰 1.68% / 0.41%。

- 侧视角的尾巴根部，改动前就有的薄卡片边仍隐约可见。
