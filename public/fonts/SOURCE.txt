Self-hosted font subsets for the interface (#20). Google Fonts is no longer linked;
these two woff2 files are the whole font payload.

file: mira-serif-sc.woff2 (74 KB, 723 glyphs, instanced at wght 200)
family-name: "Mira Serif SC" (custom name; the OFL reserved font names stay untouched)
source-font: Noto Serif SC (Source Han Serif SC), variable TTF NotoSerifSC[wght].ttf
source-url: https://raw.githubusercontent.com/google/fonts/main/ofl/notoserifsc/NotoSerifSC%5Bwght%5D.ttf
license: SIL OFL 1.1 — full text in OFL-NotoSerifSC.txt (same directory)
subset-of: every character in src/constants/translations.ts (en + ch) + printable ASCII
  + the few glyphs the chrome renders directly; the list is subset-glyphs.txt, rebuilt
  by experiments/build-font-subset.mjs and guarded by tests/unit/fontSubset.spec.ts
subset-command: fontTools varLib.instancer wght=200, then pyftsubset --flavor=woff2
  --layout-features='*' --no-hinting --desubroutinize --text-file=subset-glyphs.txt
subsetted-on: 2026-10-18 (regenerated for #111's 更多; the interface renders the
  extralight weight, so the variable source is instanced at wght 200 first)
